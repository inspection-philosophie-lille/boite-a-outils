Génère un fichier HTML nommé algorigramme.html qui utilise Cytoscape.js (version 3.23.0 via CDN) pour afficher un algorigramme interactif avec les spécifications suivantes :

Structure générale :

Le fichier doit inclure un conteneur Cytoscape (#cy) pour afficher un diagramme avec 7 nœuds et 7 liens définis par un JSON initial (fourni ci-dessous).
Utiliser la police 'Inter' (via Google Fonts) pour le texte et 'Material Symbols Outlined' pour les icônes.
Le style doit être moderne, avec un fond gris clair (#e7e7e9), des ombres néomorphiques, et des boutons ronds.


Titre et sous-titre :

Un titre <h1> avec le texte "algorigramme" (sans majuscule, en rouge, taille 24px).
Un sous-titre <h2> avec le texte "construire un raisonnement" (sans majuscule, en noir, taille 18px).
Les deux sont centrés horizontalement (left: 50%; transform: translateX(-50%)) en haut de la page, dans un conteneur <div class="title-container">.


Comportement responsive :

Desktop (> 768px) :

Le conteneur #cy a une marge supérieure de 60px pour éviter la superposition avec le sous-titre, et une hauteur de calc(100vh - 60px).
L'algorigramme est centré horizontalement par rapport au titre/sous-titre en ajustant les positions x des nœuds (calculer le centre actuel des nœuds via la moyenne des coordonnées x, puis décaler pour aligner avec window.innerWidth / 2).
Zoom initial de 0.8 pour garantir que tout est visible sans superposition.
Menu de contrôles fixe à gauche (position left: 12px, sans bouton de bascule).


Mobile (≤ 768px) :

Le conteneur #cy occupe toute la hauteur (100vh), sans marge supérieure.
Menu coulissant (caché par défaut à left: -70px, affiché via un bouton de bascule avec l'icône 'menu' en haut à gauche).
Pas de centrage horizontal forcé ni de zoom réduit.




Menu de contrôles :

Contient des boutons pour :

Changer la forme des nœuds (rectangle ▭, losange ◇, ellipse ◯).
Ouvrir une palette de couleurs (8 couleurs : #e0e0e0, #a3bffa, #f6e58d, #ff9ff3, #ff6b6b, #55efc4, #74b9ff, #fd79a8).
Ajouter une connexion (mode où l'utilisateur clique sur un nœud source puis cible).
Importer un fichier JSON (via <input type="file"> caché).
Exporter le diagramme en JSON (algorigramme.json).
Exporter le diagramme en PNG (algorigramme.png, échelle 1.5 sur desktop, 1.2 sur mobile).


Boutons avec style néomorphique, icônes Material Symbols, et hover avec légère élévation.
Sur mobile, boutons plus petits (min-width 36px, font-size 16px).


Fonctionnalités interactives :

Ajout de nœud : En cliquant sur un bouton de forme, si aucun nœud n'est sélectionné, un nouveau nœud est créé avec un texte saisi via prompt (position aléatoire autour de x: 220-580, y: 160-420).
Édition de texte : Double-clic sur un nœud ouvre un champ <input> positionné sur le nœud pour modifier le texte (valider avec Enter, annuler avec Escape).
Suppression : Touche Delete/Backspace supprime les nœuds ou liens sélectionnés (ignoré si un champ <input> est actif).
Taille des nœuds : Ajustée dynamiquement selon le texte (largeur basée sur la longueur max, hauteur sur le nombre de lignes, max 420px/320px sur desktop, 300px/240px sur mobile).
