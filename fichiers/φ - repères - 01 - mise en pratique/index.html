règles du jeu

1. Le jeu propose deux catégories (colonne gauche et droite).

2. Des exemples mélangés sont répartis entre les deux colonnes.

3. Glissez-déposez les exemples dans la bonne catégorie.

4. Vous pouvez aussi cliquer sur un exemple pour le déplacer d'une colonne à l'autre.

5. Cliquez sur « vérifier » pour évaluer vos réponses.

6. Les exemples corrects deviennent verts, les incorrects deviennent rouges.

7. Cliquez sur « nouvelle partie » pour recommencer avec de nouveaux exemples.
