présentation

Cette application est un outil conçu pour aider les enseignants à évaluer les copies en philosophie selon des paliers de notation.

Objectif principal : visualiser et comparer les critères d'évaluation pour les deux types d'exercices :

  • La dissertation
  • L'explication de texte
paramètres
mode sombre :

Le mode sombre inverse les couleurs de l'interface pour afficher du texte clair sur un fond sombre, réduisant ainsi la fatigue oculaire dans les environnements peu éclairés et économisant la batterie sur les écrans OLED.
