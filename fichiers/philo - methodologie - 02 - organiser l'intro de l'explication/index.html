présentation

Cette application permet d'organiser une introduction d'explication de texte en replaçant les éléments dans l'ordre.


  • Objectif : reconstituer l'introduction en faisant glisser les réponses vers les bonnes catégories.
  • Origine : présentation du texte
  • Thème : la notion philosophique abordée
  • Thèse : ce que défend l'auteur
  • Intérêt philosophique : pourquoi ce texte est important
  • Problématique : l'alternative posée
paramètres
mode sombre
mode évaluation
mode daltonisme

Le mode sombre inverse les couleurs de l'interface.

Le mode évaluation masque le contenu des réponses pour une auto-évaluation.

Le mode daltonisme ajoute des symboles ✓ et ✗ aux corrections.
