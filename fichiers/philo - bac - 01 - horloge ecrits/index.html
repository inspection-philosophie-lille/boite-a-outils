présentation

Cette application est conçue pour aider à gérer le temps de l'épreuve écrite.


Fonctionnalités :

• Affichage clair de l'heure

• Mode sombre pour une meilleure lisibilité

• Possibilité de masquer les secondes

• Menu de navigation intuitif


Conseils d'utilisation :

• Raccourcis clavier pour accéder rapidement aux fonctions principales.

• Mode plein écran pour une visualisation optimale.

raccourcis clavier

H accueil

R recharger

F plein écran

M menu

ESC fermer

paramètres
mode sombre
afficher les secondes
