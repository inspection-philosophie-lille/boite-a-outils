présentation

le principe :
on place n points régulièrement espacés sur un cercle (numérotés de 0 à n-1). Puis on relie chaque point k au point (k × table) modulo n.


objectif pédagogique :
montrer qu'une opération arithmétique basique peut générer des figures complexes d'une beauté surprenante.


comment expérimenter :
• ajustez la table (le multiplicateur) et le modulo (le nombre de points).
• le mode lent dessine les traits un à un et le mode rapide fait varier automatiquement la valeur.
