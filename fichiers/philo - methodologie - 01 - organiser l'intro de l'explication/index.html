explication de texte

organiser une introduction

présentation

Cette application permet d'organiser une introduction d'explication de texte en replaçant les éléments dans l'ordre.

  • Objectif : reconstituer l'introduction en faisant glisser les réponses vers les bonnes catégories.
  • Origine : présentation du texte
  • Thème : le sujet abordé
  • Thèse : ce que défend l'auteur
  • Intérêt : pourquoi ce texte est important
  • Problématique : la question posée
paramètres
mode sombre
mode évaluation

Le mode sombre inverse les couleurs de l'interface pour afficher du texte clair sur un fond sombre, réduisant ainsi la fatigue oculaire dans les environnements peu éclairés.

Le mode évaluation masque le contenu des réponses pour permettre une auto-évaluation. Raccourci clavier : E

raccourcis clavier
Accueil H accueil (site académique)
Recharger R recharger la page
Plein écran F plein écran
Menu M ouvrir / fermer le menu
Évaluation E activer/désactiver le mode évaluation
ESC fermer les menus
? afficher cette aide

Mode sombre : disponible dans le menu paramètres

Mode évaluation : disponible dans le menu paramètres ou via E
