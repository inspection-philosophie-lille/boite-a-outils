Prompt :

Créez un fichier HTML nommé index.html qui implémente un jeu interactif d'appariement de mots en français, conçu pour réviser des repères et leurs définitions. Le fichier doit inclure du HTML, du CSS et du JavaScript, avec les spécifications suivantes :
Structure HTML

    Langue et encodage : Le document HTML doit être en français (lang="fr") avec un encodage UTF-8.
    Méta-données : Inclure une balise <meta> pour le viewport avec width=device-width, initial-scale=1.0 et une favicon liée à ../../src/favicon.ico.
    Titre : Le titre de la page doit être "appariement de mots".
    Corps :
        Un paragraphe avec la classe title contenant le texte "appariement de mots".
        Un paragraphe avec la classe subtitle contenant le texte "réviser les repères".
        Un conteneur <div> avec la classe container contenant :
            Deux <div> avec la classe column, chacun contenant une table (<table>) avec les IDs respectifs repereTable et definitionTable.
            Un élément <canvas> avec l'ID lineCanvas pour dessiner des lignes de connexion.
        Un bouton avec l'ID actionButton affichant initialement le texte "Vérifier" et déclenchant la fonction JavaScript performAction() au clic.
    Script externe : Inclure un fichier JavaScript externe ../../src/reperes.js qui contient un tableau reperes (non fourni, supposé contenir une liste d'objets avec des propriétés parts contenant des objets {name, definition}).

Style CSS

    Classe title : Marge de 2vh 1rem, alignement centré, texte rouge, taille de police clamp(1.8rem, 5vw, 2.5rem), gras.
    Classe subtitle : Marge 0, alignement centré, texte noir, taille de police clamp(1rem, 3vw, 1.2rem).
    Classe container : Affichage flex en ligne, centré, marge 2vh 1rem, largeur 90%, largeur maximale 1200px, écart de 2rem entre les éléments.
    Classe column : Flex 1, largeur minimale 0.
    Tables : border-collapse: separate, espacement de bordure 0.5rem, largeur 100%.
    Cellules <td> : Bordure arrondie 0.5rem, padding 0.75rem, texte centré, curseur pointeur, fond #e0e0e0, ombre néomorphique (box-shadow: 0.3rem 0.3rem 0.6rem #bebebe, -0.3rem -0.3rem 0.6rem #ffffff), taille de police clamp(0.9rem, 2.5vw, 1rem), texte avec césure automatique.

Au survol, fond #d1d1d1 avec ombre interne. À l'activation, fond #c0c0c0 avec ombre interne.
    Classe reload-icon : Taille de police clamp(1.5rem, 4vw, 2rem), couleur rouge, transformation translateY(-0.1rem), transition 0.3s. Au survol ou activation du bouton, translateY(0).
    Media Queries :

JavaScript

    Initialisation :
        Variables globales : startX, startY, drawing (booléen initialisé à false), canvas (ID lineCanvas), ctx (contexte 2D du canvas), usedCells (Set vide), currentAction (initialisé à "check"), currentRepere (null), currentDefinition (null), links (tableau vide), selectedReperes (tableau vide).
        Fonction resizeCanvas : Redimensionne le canvas à la taille du conteneur .container (largeur et hauteur).
        Écouteurs d'événements : resize et load pour appeler resizeCanvas.
    Fonctions utilitaires :
        isVerticalLayout : Retourne true si la largeur de la fenêtre est ≤ 768px.
        getRandomElements : Mélange un tableau et retourne les count premiers éléments.
        loadReperes :
            Vide les tables repereTable et definitionTable.
            Récupère toutes les parties depuis reperes (supposé être un tableau d'objets avec parts contenant {name, definition}).
            Sélectionne 5 parties aléatoires, mélange leurs noms et définitions séparément.
            Crée des lignes de table avec des cellules <td> pour les noms (dans repereTable) et les définitions (dans definitionTable), avec dataset.index pour chaque cellule.
            Retourne les parties sélectionnées.
        drawLink(startX, startY, endX, endY, color = 'black') :
            Dessine une ligne avec une flèche entre (startX, startY) et (endX, endY) sur le canvas.
            Longueur de la tête de flèche : 10px. Angle calculé avec Math.atan2.
            Style : strokeStyle = color, lineWidth = 2.
        resetDrawing : Réinitialise drawing, currentRepere, currentDefinition, currentAction à "check", et met à jour le texte du bouton en "Vérifier".
    Fonction selectCell(event, type, info) :
        type est 'repere' ou 'definition', info est le texte de la cellule.
        Ignore les cellules déjà utilisées (dans usedCells).
        Calcule les coordonnées relatives au canvas en utilisant getBoundingClientRect.
        Variables locales : isVertical (via isVerticalLayout), totalCells = 5.
        Pour déterminer la position horizontale (startX, endX), utilise l'index du repère dans selectedReperes :
            Si type === 'repere', trouve repereIndex via selectedReperes.findIndex(part => part.name === info).
            Si type === 'definition' et currentRepere existe, utilise son index dans selectedReperes.
            Si pas de repère (première sélection d'une définition), utilise repereIndex si disponible.
        Si type === 'repere' :
            Si drawing est true et currentDefinition existe :
                Calcule lineX :
                    Vertical : rect.left + (rect.width * (repereIndex + 0.5) / totalCells) - canvasRect.left.
                    Horizontal : rect.right - canvasRect.left.
                startY : rect.top + rect.height / 2 - canvasRect.top.
                endX : lineX (vertical) ou currentDefinition.startX (horizontal).
                endY : currentDefinition.startY.
                Dessine la flèche, ajoute le lien à links avec {repere, definition, lineId: {startX: lineX, startY, endX, endY}}, marque les cellules comme utilisées, réinitialise le dessin.
            Sinon (début d'un nouveau lien) :
                Calcule startX :
                    Vertical : rect.left + (rect.width * (repereIndex + 0.5) / totalCells) - canvasRect.left.
                    Horizontal : rect.right - canvasRect.left.
                startY : rect.top + rect.height / 2 - canvasRect.top.
                Met à jour currentRepere, drawing = true, currentDefinition = null.
        Si type === 'definition' :
            Si drawing est true et currentRepere existe :
                Calcule lineX :
                    Vertical : rect.left + (rect.width * (repereIndex + 0.5) / totalCells) - canvasRect.left.
                    Horizontal : rect.left - canvasRect.left.
                startX : currentRepere.startX.
                startY : currentRepere.startY.
                endY :
                    Vertical : rect.top + rect.height * 0.1 - canvasRect.top.
                    Horizontal : rect.top + rect.height / 2 - canvasRect.top.
                Dessine la flèche, ajoute le lien à links, marque les cellules comme utilisées, réinitialise le dessin.
            Sinon (début d'un nouveau lien) :
                Calcule startX :
                    Vertical : rect.left + (rect.width * (repereIndex + 0.5) / totalCells) - canvasRect.left (si repereIndex disponible).
                    Horizontal : rect.left - canvasRect.left.
                startY :
                    Vertical : rect.top + rect.height * 0.1 - canvasRect.top.
                    Horizontal : rect.top + rect.height / 2 - canvasRect.top.
                Met à jour currentDefinition, drawing = true, currentRepere = null.
    Fonction performAction :
        Selon currentAction :
            "check" : Appelle checkLinks.
            "correct" : Appelle correctLinks.
            "reload" : Appelle reload.
    Fonction checkLinks :
        Pour chaque lien dans links, vérifie si la définition correspond au repère dans selectedReperes.
        Redessine la flèche en vert (correct) ou rouge (incorrect).
        Met à jour currentAction à "correct" et le texte du bouton à "Corriger".
    Fonction correctLinks :
        Efface le canvas.
        Pour chaque repère dans selectedReperes :
            Trouve les cellules correspondantes dans repereTable et definitionTable.
            Calcule les coordonnées :
                lineX :
                    Vertical : repereRect.left + (repereRect.width * (index + 0.5) / totalCells) - canvasRect.left.
                    Horizontal : repereRect.right - canvasRect.left.
                startY : repereRect.top + rect.height / 2 - canvasRect.top.
                endX : lineX (vertical) ou defRect.left - canvasRect.left (horizontal).
                endY :
                    Vertical : defRect.top + defRect.height * 0.1 - canvasRect.top.
                    Horizontal : defRect.top + defRect.height / 2 - canvasRect.top.
            Dessine la flèche en vert.
            Affiche un avertissement en console si une cellule est introuvable.
        Met à jour currentAction à "reload" et le texte du bouton à <span class="reload-icon">&#8635;</span>.
    Fonction reload :
        Vide links, efface le canvas, vide usedCells, vide les tables.
        Appelle loadReperes, réinitialise le dessin, ajoute les écouteurs, redimensionne le canvas.
    Fonction addEventListeners :
        Ajoute des écouteurs de clic à toutes les cellules de repereTable et definitionTable, appelant selectCell avec le type approprié et le texte de la cellule.
    Événement window.onload :
        Appelle loadReperes, resizeCanvas, et addEventListeners.

Exigences spécifiques

    Les flèches tracées par l'utilisateur sur un écran mobile (≤ 768px, disposition verticale) doivent avoir la même position horizontale que celles tracées par correctLinks, basée sur l'index du repère dans selectedReperes. Cela garantit qu'il n'y a aucun décalage visuel si les réponses de l'utilisateur sont correctes.
