oral φ est un chronomètre double développé pour les épreuves de contrôle (oraux de rattrapage)

• 1er timer : exposé
(10 minutes)

• 2nd timer : entretien
(10 minutes)

• code couleur :
vert : > 3 minutes
orange : 1-3 minutes
rouge : < 1 minutes

• passage automatique au 2nd timer

• raccourcis clavier

raccourcis clavier
accueil H renvoi au site académique
⟳ R recharger la page
plein écran F entrer/sortir du plein écran
menu M ouvrir/fermer le menu
ESC fermer sous-menu/menu
espace > lancer/pause le chrono actif
R réinitialiser le chrono actif

• le mode sombre est accessible dans "paramètres"

• les timers s'enchaînent automatiquement

paramètres
mode sombre
animations
mode daltonien
mode évaluation

mode daltonien : affiche des icônes ✓ / ✗ et utilise des couleurs bleu / rouge au lieu de vert / rouge.

mode évaluation : les réponses sont évaluées uniquement à la fin du quiz.
