présentation

🎮 simulation de nuée
les boids ne donnent pas une réponse simple à « qu'est-ce que la liberté ? », ils en illustrent brillamment les paradoxes et les conditions de possibilité.

🖱️ CONTRÔLES SOURIS
curseur attire les boids (quand activé dans paramètres)
🐦 COMPORTEMENT
• les oiseaux suivent trois règles : séparation, alignement, cohésion
• le curseur peut attirer les oiseaux (option dans paramètres)
• les oiseaux maintiennent une distance minimale entre eux même attirés
• ajuster le nombre d'oiseaux dans "paramètres"
