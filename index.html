présentation

cette application rassemble des outils pédagogiques pour la philosophie, l'HLP et l'option math-philo.

  • objectif : réviser les repères, les notions, les cours, les auteurs.
  • méthodologie : organiser une introduction, construire un raisonnement.
  • questionnement : identifier arguments et sophismes.
  • baccalauréat : s'entraîner pour l'écrit et l'oral.
